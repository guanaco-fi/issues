# [guanaco.fi](https://guanaco.fi) Issues

This repository is used exclusively to track and manage externally reported issues.

## Report an issue

1. Open the repository's [Issues](https://github.com/guanaco-fi/issues/issues) page.
2. Select **New issue**.
3. Add a clear title that summarizes the problem.
4. Describe what happened, what you expected to happen, and the steps needed to reproduce it.
5. Include relevant screenshots, public links, and environment details when helpful.
6. Submit the issue and follow the conversation for questions or updates.

Before submitting, search the existing issues to avoid creating a duplicate.
